# Accessibility

Positronikal is committed to making our tools and documentation usable by everyone.

## Command-Line Output

- All output is plain text and works without color or ANSI formatting
- No information is conveyed by color alone
- Output is structured for screen reader compatibility
- Exit codes are used consistently: `0` for success, non-zero for errors

## Documentation

- All documentation is written in plain Markdown
- Code examples use descriptive comments rather than visual-only conventions
- No content requires images or graphical elements to understand

## Forensic and Legal Context

Documentation in this project — including METHODOLOGY.md and VALIDATION.md — is written to be readable without specialized tooling. Forensic documentation intended for legal proceedings should be accessible to judges, jurors, and expert witnesses who may use assistive technologies. Plain-text formats are used throughout to support this.

## Reporting Accessibility Issues

If you encounter an accessibility barrier, please report it:

- **GitHub Issues**: open an issue with the label `accessibility`
- **Email**: admin@positronikal.tech

We aim to respond to accessibility reports within 5 business days.
